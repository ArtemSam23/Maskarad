# Источники словарей

| Файл | Содержание | Источник и лицензия |
|---|---|---|
| `first_names_male.txt`, `first_names_female.txt`, `patronymics.txt`, `surnames.txt` | Русские имена, отчества, фамилии (именительный падеж; падежные формы выводятся правилами в коде) | Пакет `russian-names` 0.1.2 — MIT, https://github.com/cybermatt/russian-names |
| `first_names_diminutive.txt` | Уменьшительные и разговорные формы имён | Составлен вручную |
| `cities_ru.txt` | Города России | Открытые данные HFLabs, https://github.com/hflabs/city |
| `regions_ru.txt` | Регионы России | Открытые данные HFLabs, https://github.com/hflabs/region |
| `cities_world.txt` | Столицы и крупные города СНГ и мира | Составлен вручную |
| `countries.txt` | Страны и формы для определения гражданства | Составлен вручную |
| `public_persons.txt` | Публичные персоны (исключения из ПДн) | Составлен вручную |

Все файлы — простой текст в UTF-8, одна запись на строку, строки, начинающиеся с `#`, игнорируются.
Файлы можно дополнять; дополнительные словари подключаются в конфигурации (`dictionaries.extra`).
